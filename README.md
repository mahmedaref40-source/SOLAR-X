# ☀️ SOLAR X - Solar PV Site Survey & System Sizing Platform

An interactive full-stack engineering tool designed for solar energy professionals to conduct field audits, size PV systems (On-Grid, Off-Grid, Hybrid), and evaluate connected loads dynamically.

---

## 🚀 Key Features

* **Multi-Step Site Survey (8 Pages):** Guided workflow covering client info, grid stability, azimuth orientation, inverter rooms, and earthing protection.
* **Dynamic Load Calculation Engine:** 21+ appliances with real-time surge factor analysis and day/night Wh segregation to avoid inverter oversizing.
* **Top-View Rooftop Sketch Pad:** Interactive HTML5 Canvas allowing engineers to sketch roof layouts directly on site.
* **Engineering Tools:** Integrated modern scientific calculator and an AI-powered assistant for solar sizing consultations.
* **Database Integration:** Local project persistence powered by SQLite and SQLAlchemy.

---

## 🛠️ Tech Stack

* **Backend:** Python 3, Flask, Flask-SQLAlchemy, SQLite
* **Frontend:** Vanilla JavaScript (ES6+), HTML5, CSS3, Bootstrap 5, FontAwesome
* **AI:** Google GenAI / Gemini API
